# Средний расход арматуры — SP_test

Самостоятельная сборка для Revit 2023 (.NET Framework 4.8, x64). Кнопка: SP_test → Армирование → Средний расход арматуры.

Готовые DLL, .addin и архив интеграции в первоначальные исходники доступны в [dist](dist/README.md).

## Текущая версия

Дополнительные изменения проверки/записи и интерфейса из коммита 0bc6a01 отменены. За основу снова взяты исходники 53bcac7. Сохранены файлы самостоятельной сборки, темы окон и регистрации кнопки SP_test. Изменён принцип расчёта по предоставленному графу Dynamo.

- Объём: параметр элемента «Объем» (резерв: «Объём» или HOST_VOLUME_COMPUTED), с переводом типизированного объёма в м³. Нет отбора по материалам и Мтрл.КодМатериала.
- Режим по параметру: комплект ADSK_Комплект / RNF.Раздел и значение SP_ВРС_Группирование (или выбранного параметра). Исходный режим по отметке сохранён отдельно.
- Для арматуры требуется RNF.Учёт в спецификации. Заполненная RNF.Марка конструкции в режиме по параметру не требуется.
- Элементы с параметром типа SP_Класс арматуры = 75 или 61 исключаются до группировки и расчёта массы в обоих режимах. Значение экземпляра не используется; при отсутствующем параметре типа элемент не исключается этим правилом. Читаются числовые и текстовые значения 75 и 61, без округления соседних значений до исключаемых классов.
- Каркас исключается по ключевой пометке типа, как в графе; пометка экземпляра не используется.
- RNF.Тип массы читается с типа семейства; при отсутствии — с экземпляра.
- Масса = RNF.Масса элемента × RNF.Количество элементов × RNF.Количество сборок_число. При типе массы 1 дополнительно применяется RNF.Длина пм. Если длина отсутствует, используется обычное количество, как в Python графа.
- Нулевое количество сборок не заменяется единицей. Если обязательное числовое значение не читается, вклад пропускается. Числовые параметры предполагаются в кг/метрах; типизированная длина и погонная масса переводятся в м и кг/м.
- Расход = сумма масс / сумма объёмов. Группировка, отчёт, отдельная кнопка записи и обработка нулевого объёма — из исходного плагина.
- Запись — исходная: индивидуальная масса на RNF-элементе, расход группы на конструктивных элементах.

Не перенесены ошибки графа: сравнение всего списка типов массы с числом 1 и запись полной массы группы в каждый конструктивный элемент. Формула применяется поэлементно, как указано в описании группы узлов Dynamo.

Отменены снимок документа, блокировка записи после изменений модели, запрет неполных групп, атомарная запись и общий средний расход в сводке из предыдущей версии. Самостоятельная сборка не зависит от SP_Addin.dll. Ограничение «только модели КР» недоступно без отсутствующего общего сервиса; семейственные документы запрещены.

## Сборка и установка

Сборка: dotnet build SP.ReinforcementCoeff.csproj -c Release -p:RevitVersion=2023
Проверки: dotnet run --project tests/CalculationTests.csproj -c Release

DLL: bin/Release/2023/net48/SP.ReinforcementCoeff.dll.
Установка DLL: C:/RevitAddins/ReinforcementCoeff/SP.ReinforcementCoeff.dll.
Манифест SP.ReinforcementCoeff.addin: %APPDATA%/Autodesk/Revit/Addins/2023, затем перезапуск Revit.

Проверяются сборка против установленного API Revit 2023 и 7 проверок формулы. На реальной модели Revit эта версия ещё не проверена.
